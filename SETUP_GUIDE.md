# Відкриття та перевірка CinemaBooking

## Що потрібно
- Комп’ютер і браузер.
- Інтернет та обліковий запис GitHub для розміщення документації.
- За бажанням — текстовий редактор із підтримкою Markdown.

## Відкриття на GitHub
1. Створи репозиторій `documentation-lab-kopyl`.
2. Завантаж у корінь усі п’ять файлів `.md` з цього комплекту.
3. Збережи завантаження комітом, наприклад `Add project documentation`.
4. Відкрий головну сторінку репозиторію: GitHub покаже вміст `README.md`.
5. Перейди за посиланнями в таблиці документів, щоб прочитати інші файли.

## Перегляд на комп’ютері
1. Завантаж репозиторій через **Code → Download ZIP**.
2. Розпакуй архів.
3. Відкрий файли в редакторі. У VS Code для попереднього перегляду Markdown натисни **Ctrl + Shift + V**.

## Запуск макета
У цій роботі макет описаний таблицею в `USER_GUIDE.md`. Його перегляд не потребує встановлення сервера, бази даних або додаткових пакетів. Виконуваного коду немає, тому запустити справжнє бронювання поки неможливо. API-запити з документації також не надсилаються до реального сервера.

## Перевірка роботи
- У корені репозиторію є всі п’ять потрібних файлів.
- Заголовки, списки, таблиці та блоки коду відображаються правильно.
- Посилання з `README.md` відкривають відповідні документи.
- Приклад місця, сеансу та бронювання в інструкції збігається з прикладами API.

Якщо ці пункти виконані, комплект документації відкривається правильно.
