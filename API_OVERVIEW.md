# Огляд API CinemaBooking

API вигадане та наведене для навчання. Сервер у цьому репозиторії не реалізований. Адреса `https://cinema.example/api` є умовною, запити не призначені для реального виконання.

Дані передаються у форматі JSON. У прикладі одне бронювання містить одне місце. Час сеансу вказано з часовим зміщенням Києва на відповідну дату.

## 1. GET /sessions — список сеансів
Повертає сеанси на обрану дату.

### Запит
```http
GET /api/sessions?date=2026-10-27 HTTP/1.1
Host: cinema.example
Accept: application/json
```

### Відповідь: 200 OK
```json
{
  "sessions": [
    {
      "id": 101,
      "movie": "Космічна подорож",
      "starts_at": "2026-10-27T18:00:00+02:00",
      "hall": 1,
      "price_uah": 180
    }
  ]
}
```
Якщо сеансів на дату немає, повертається `200` і порожній масив `sessions`. Неправильний формат дати повертає `400`.

## 2. GET /sessions/101/seats — місця на сеанс
Повертає номери місць та їх доступність.

### Запит
```http
GET /api/sessions/101/seats HTTP/1.1
Host: cinema.example
Accept: application/json
```

### Відповідь: 200 OK
```json
{
  "session_id": 101,
  "seats": [
    {"number": 11, "available": false},
    {"number": 12, "available": true},
    {"number": 13, "available": true}
  ]
}
```
Для скорочення показано лише частину місць. Якщо сеансу не існує, повертається `404`.

## 3. POST /bookings — створення бронювання
Приймає сеанс, місце та контактні дані користувача.

### Запит
```http
POST /api/bookings HTTP/1.1
Host: cinema.example
Content-Type: application/json
Accept: application/json

{
  "session_id": 101,
  "seat_number": 12,
  "name": "Єгор",
  "email": "yehor@example.com"
}
```

### Відповідь: 201 Created
```json
{
  "booking_id": "CN-1001",
  "session_id": 101,
  "seat_number": 12,
  "status": "confirmed",
  "price_uah": 180
}
```
Після успішного створення місце 12 стає недоступним. Сервер має перевірити його доступність перед збереженням, щоб уникнути подвійного бронювання.

### Приклад помилки: 409 Conflict
```json
{
  "error": "SEAT_UNAVAILABLE",
  "message": "Це місце вже заброньоване. Оберіть інше."
}
```

## Коди відповідей
| Код | Значення | Коли використовується |
| --- | --- | --- |
| 200 | Успішно | Отримано список сеансів або місць |
| 201 | Створено | Збережено нове бронювання |
| 400 | Неправильні дані | Немає обов’язкового поля, некоректний email або дата |
| 404 | Не знайдено | Сеанс або місце не існує |
| 409 | Конфлікт | Місце вже заброньоване |
| 500 | Помилка сервера | Не вдалося обробити запит через внутрішній збій |

Помилки мають поля `error` з коротким кодом і `message` з поясненням для користувача.
