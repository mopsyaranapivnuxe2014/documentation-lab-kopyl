# CinemaBooking — бронювання квитків у кінотеатр

**Лабораторна робота «Документація в ІТ»**  
**Варіант 9. Копил Єгор Віталійович, група 372.**

## Про проєкт
CinemaBooking — навчальний проєкт вебсистеми для бронювання квитків у кінотеатр. Користувач може обрати фільм, сеанс і вільне місце без дзвінка до каси. Це допомагає заздалегідь спланувати похід у кіно.

> Репозиторій містить лише документацію. Інтерфейс, API та історія змін описані як приклад майбутнього продукту. Готової програми й реального сервера тут немає.

## Основні функції
- Перегляд фільмів і розкладу сеансів.
- Вибір вільного місця в залі.
- Створення бронювання на ім’я та email.
- Отримання номера бронювання для каси.

## Для кого
Для відвідувачів кінотеатру та працівників каси, які перевіряють бронювання. У навчальному прикладі оплата відбувається в касі.
